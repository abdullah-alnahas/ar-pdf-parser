**One real issue**: `_resolve_dep_closure` extra-marker filtering at line 238 uses string matching:
```python
if "extra ==" in raw or 'extra=="' in raw or "extra=='" in raw:
    continue
```
This is fragile. `extra == "ml"` (with spaces around `==`) would pass, but `extra!="ml"` or negated markers wouldn't be caught — though that's not a concern for this project since no dep uses negated extra markers. Acceptable for v1, but worth noting.
