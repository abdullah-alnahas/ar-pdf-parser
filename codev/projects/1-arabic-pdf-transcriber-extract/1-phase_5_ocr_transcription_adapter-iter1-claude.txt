### Code Quality

**Good.** Few observations:

1. **Model selection rationale** — well-documented comparison table in docstring. GOT-OCR-2.0-hf chosen (Apache-2.0, ~1.1 GB) over AIN (too large), arabic-large-nougat (GPL), nougat-base (NC + Latin-only). Sound reasoning.

2. **Confidence computation** (`_confidence_from_scores`) — geometric mean of per-token softmax probs is correct. Handles edge cases (no scores, empty scores, count=0). Returns `None` gracefully when model doesn't expose scores.

3. **Degenerate cell crop** — silently returns `("", None)` for table cells vs raising `OCRTranscriptionError` for top-level regions. Right tradeoff — one bad cell shouldn't nuke whole table.

4. **Minor concern**: `hf_ocr.py:224` — `processor(images=image, ...)`. Some HF processors expect `image` (singular) as first positional arg, not `images` keyword. GOT-OCR-2.0-hf's processor should handle this, but it's worth noting the slow test is the only thing catching API mismatches. Not blocking — this is inherent to stub-based testing.

5. **`_ensure_loaded` broad except** (line 157) — catches all `Exception`. Pragmatic for model loading, where failure modes are diverse. Wraps into `ModelDownloadError` with actionable message including the `huggingface-cli download` command. Good.
